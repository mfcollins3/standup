# Naked Standup Instructions

## About Naked Standup

* The name of the product that you are contributing to is **Naked Standup**.
* The product information is stored in the Product Requirements Document (prd)
  in the `docs/prd` subdirectory.

## Software Architecture

* Capture important architectural decisions using
  [Architectural Decision Records](https://adr.github.io) (ADRs).
  * Use the `software-architecture:adr` skill to write and manage ADRs.
  * Store ADRs in the `docs/adrs` subdirectory.

## Writing Code

### Commit Messages

* Use the [Conventional Commit specification](https://www.conventionalcommits.org/en/v1.0.0/)
  to format commit messages.
  * Use the [rules](docs/contributing/commit_messages.md) for instructions on
    writing commit messages.
