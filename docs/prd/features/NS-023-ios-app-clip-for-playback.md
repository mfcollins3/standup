# NS-023: iOS App Clip for playback

[Back to the PRD](../README.md)

**Requirement ID:** NS-023

**User Story:** As a stakeholder, I want to play a shared status report instantly on iPhone without installing the app so that viewing a link is quick and lightweight.

**Acceptance Criteria:**

- [ ] Opening a share link or App Clip code on an iPhone offers the App Clip, which plays the video.
- [ ] The App Clip size meets Apple's limits and starts quickly.
- [ ] The App Clip can show a prompt to install the full app.
- [ ] Where the App Clip can't run, the link opens the web player.
- [ ] The App Clip can receive notifications for the report where Apple allows it.

**Technical Notes:** Use an App Clip with associated domains and an App Clip Experience. Playback only; no recording or sign-in required for public links.

**Priority:** Should-have
