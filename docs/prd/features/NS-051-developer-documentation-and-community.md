# NS-051: Developer documentation and community

[Back to the PRD](../README.md)

**Requirement ID:** NS-051

**User Story:** As a developer, I want to find documentation, examples and a place to ask questions so that I can succeed with the API and help others.

**Acceptance Criteria:**

- [ ] A public developer site hosts guides, the API reference (from the OpenAPI spec), authentication walkthroughs and webhook documentation.
- [ ] Example code is provided for common tasks (for example list reports, download a transcript, verify a webhook).
- [ ] A changelog and deprecation policy are published.
- [ ] A public community channel (for example forum or GitHub Discussions) is linked from the product.
- [ ] Customers can export all of their data through the API or a self-service export (NS-040).
- [ ] Documentation covers the MCP server, including connecting popular AI clients.

**Technical Notes:** Supports the goal of building a community and giving customers access to their data.

**Priority:** Should-have
