# Contribution Guidelines for Naked Standup

This document is intended for use by developers who are contributing new
features or bug fixes to Naked Standup. This document covers the conventions,
tools, and style information that developers should follow.

## Writing commit messages

Commit messages are an important source of documentation for the project. Commit
messages keep a history of what changes when into a product and why. It is
important that all commit messages are properly formatted and well written. To
learn how to write proper commit messages, please review the
[commit message guidelines](docs/contributing/commit-message-guidelines.md)
document.
